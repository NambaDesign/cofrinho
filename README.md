# Cofrinho

App de finanças do Pedro e da Rafa: lançamento rápido de gastos e recebimentos, categorias e cartões por pessoa, compras parceladas, visão juntos e planos com meta de economia.

- App web instalável (PWA), funciona offline.
- Dados no Firebase (Firestore + Authentication); acesso limitado pelas regras em `firestore.rules`.
- Publicado pelo GitHub Pages: https://nambadesign.github.io/cofrinho/
